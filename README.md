# tracker-page

Страница личного трекера — то, что приложение скачивает как обновление.

`tracker.html` здесь **собранный** файл: исходник и Android-обёртка лежат
в приватном репозитории, сюда попадает только результат сборки.

Приложение раз в сутки сверяет метку `TRACKER_BUILD` в начале файла со своей и,
если здесь новее, скачивает и включает при следующем запуске. Если новая
страница не поднимется, приложение само вернётся к версии из APK.

Файл самодостаточный: его можно просто открыть в браузере.
