# tracker-page

Страница личного трекера — то, что приложение скачивает как обновление.

`tracker.html` здесь **собранный** файл: исходник и Android-обёртка лежат
в приватном репозитории, сюда попадает только результат сборки.

`build.txt` — одна строка, метка сборки. Приложение спрашивает её при каждом
открытии и возвращении: это несколько байт вместо 450 КБ страницы. Если метка
здесь свежее своей, оно скачивает `tracker.html` и сразу его включает — когда в
этот момент ничего не набирается, иначе при следующем возвращении. Если новая
страница не поднимется, приложение само вернётся к версии из APK.

Метка в `build.txt` и `TRACKER_BUILD` в начале страницы всегда должны совпадать:
оба файла кладёт `tools/make_asset.py`.

Файл самодостаточный: его можно просто открыть в браузере.
